Come funziona

Tre passi verso la ricerca intelligente

Nimbus non sposta le tue foto. Scarica ogni immagine solo in memoria, calcola un vettore semantico e salva percorso + embedding in SQLite. Poi cerchi con il linguaggio naturale.

01

Collega WebDAV

Configura pCloud (EU o US) o qualsiasi server WebDAV con le credenziali nel file .env. Un comando Docker e sei online.

02

Indicizza la libreria

Nimbus attraversa le cartelle, decodifica JPEG, PNG, WebP e HEIC in memoria e crea embedding a 512 dimensioni con OpenCLIP. Puoi chiudere il browser: l'indicizzazione continua sul server.

03

Cerca per significato

Scrivi una descrizione in italiano o inglese. Il modello confronta il testo con i vettori salvati e restituisce le foto più simili, con anteprime e visualizzatore a schermo intero.

Funzionalità

Tutto ciò che serve, niente di superfluo

Un'interfaccia web leggera, senza build step. Tema chiaro/scuro, PWA installabile, ricerca per posizione GPS e molto altro.

Ricerca semantica

Scene, oggetti, illuminazione, stile fotografico — il modello capisce il contenuto visivo, non i nomi dei file.

Ricerca per luogo

Cerca foto vicino a una città, un indirizzo o alla tua posizione attuale, usando i dati GPS estratti durante l'indicizzazione.

Indicizzazione riprendibile

Salta i file già indicizzati. Interrompi e riavvia quando vuoi. Opzionale: indicizzazione automatica giornaliera.

Tag dalla libreria

Dopo l'indicizzazione, Nimbus stima i temi più comuni (spiaggia, ritratto, cibo…) confrontando ogni foto con una lista di concetti.

Self-hosted e sicuro

Tutto gira sulla tua macchina. Autenticazione HTTP Basic opzionale. Metti HTTPS davanti con nginx o Caddy su un VPS.

PWA installabile

Aggiungi Nimbus alla schermata home su desktop e mobile. Shell offline per l'interfaccia; ricerca e foto richiedono il server.

Privacy

I tuoi originali non lasciano il cloud

Solo vettori, non copie

Durante l'indicizzazione ogni immagine viene scaricata solo in RAM, elaborata e scartata. Sul disco locale resta solo il database SQLite con percorsi WebDAV e embedding numerici.

  • Nessuna copia permanente delle foto sul server Nimbus
  • Anteprime e immagini complete in streaming via proxy WebDAV
  • Progetto indipendente, non affiliato a pCloud AG

Avvio rapido

Online in pochi minuti

Clona il repository, configura le credenziali WebDAV e avvia con Docker Compose. Poi apri l'app, indicizza e cerca.

# 1. Configura
cp .env.example .env
# modifica PCLOUD_USERNAME, PCLOUD_PASSWORD, PCLOUD_WEBDAV_URL

# 2. Avvia
docker compose up --build

# 3. Apri http://localhost:8000/app
